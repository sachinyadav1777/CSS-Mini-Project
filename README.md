📸 Photography Sidebar Menu

A simple and stylish sidebar navigation menu built using HTML and CSS. It features a photography background, smooth slide animations, Font Awesome icons, and social media links.

✨ Features

Slide-in sidebar navigation
Open and close toggle using a checkbox
Smooth CSS transitions and hover effects
Font Awesome icons
Photography background image
No JavaScript required

🛠️ Technologies Used

-HTML5

-CSS3

-Google Fonts (Poppins)

-Font Awesome

📂 Project Structure

Photography-Sidebar-Menu/

├── index.html

├── style.css

├── photo.jpg

└── README.md


🚀 How to Run

Download or clone the repository.
Keep index.html, style.css, and photo.jpg in the same folder.
Open index.html in your browser.

📚 Learning Outcomes

HTML structure and CSS styling
CSS transitions and hover effects
Checkbox-based navigation toggle
Font Awesome icon integration
